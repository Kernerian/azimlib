# Fontes próprias do experimento RGBA já publicado

tk.py e pillow.py preservam os hashes do modo `after` de
docs/performance/viewer-100.json e viewer-200.json. O experimento precede os
setters públicos de tamanho/DPI e a transferência antecipada de callbacks.
Os números antigos não são uma medição dessas alterações posteriores.

Código próprio BSD-3-Clause, somente referência de desenvolvimento, fora do wheel.
Não atualizar esses snapshots para acompanhar o runtime atual.
