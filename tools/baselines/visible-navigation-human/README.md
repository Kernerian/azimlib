# Medição de input nativo Windows

Snapshot exato do script que gerou o registro visible-navigation-brazil.json.
O registro contém pan/zoom/bordas/histórico e fechamento na janela Windows. O script não injeta input. O driver seguinte adiciona
apenas edições programáticas de limites para medir um caso pesado; esses
dados não são apresentados como eventos físicos de mouse/teclado.
