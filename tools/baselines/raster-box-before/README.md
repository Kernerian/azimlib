# Own renderer before banded BOX reduction

Azimlib snapshot after first-shape tile reuse and temporary-buffer release,
before reducing the final supersampled canvas in aligned bands. Own source,
covered by the project license; development comparisons only, never runtime.

Use `compare_raster_versions.py` and `compare_raster_memory.py` with this
baseline directory. The two renderers must produce identical PNG bytes.
