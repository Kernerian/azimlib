# Own Windows visual references

Seventeen PNG exports from fourteen deterministic Azimlib scenes, including three
100/200-dpi pairs. The reference was generated from the installed development
engine on Windows. It is a comparison baseline, not an approved gold standard or
a Matplotlib export.

`manifest.json` preserves platform, package versions, installed runtime hashes,
canonical source hashes, example/generator/font hashes and exact image hashes.
The recorded commit identifies the original runtime checkout; the new generator
is identified separately by its hash. Human approval remains pending.

Compositions and tooling are original BSD-3-Clause material. Geographic layers
retain Natural Earth's public-domain terms; DejaVu text and palettes retain
the notices in the project's LICENSE, THIRD_PARTY_LICENSES.md and licenses/.
See docs/visual-review-0.3.md for scope and reproduction.
