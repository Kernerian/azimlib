Unchanged acceptance and historical evidence

  • GPU: exact frame p95 <=33 ms, complete response <=100 ms, memory/parity, frozen repetitions/workload and physical ARM64 GPU subgate remain.
  • Science: centers 2 km, boundaries 3 km, solar contacts 30 s, lunar contacts 60 s, magnitude/obscuration 0.001; no relaxed tolerances or removed failures.
  • Planet: complete real dump, date/SHA-256, EOF, counts, memory/disk/time and zero missing/corrupt references under the existing procedure.
  • Observed results keep successes and unresolved checks distinct. No failed/indeterminate check was converted to a pass.
  • Later evidence must name the version/commit that fulfills a gate. It must not retroactively certify the released 0.4 implementation or rewrite old reports.

Only these four explicitly identified requirements are deferred out of the 0.4 delivery scope. Functional regressions, corrupt outputs, resource violations, licensing and privacy failures still block delivery. The scoped release checker remains fail-closed and must not silently ignore arbitrary unchecked IDs. Preparation and publication are separate purposes.

Future sequence

0.4.1 preserves supported public signatures/semantics and accepts compatible fixes/refinements. Planet trial is conditional on infrastructure; scientific gates have no promised completion in that patch release.

0.5.0 remains Planetary Cartography / Beyond Earth: public body models, body-specific coordinates/geodesy/projections, planetary DEMs/images, relief, illumination and existing map Artists. Deep renderer/science changes can serve these foundations. Global eclipse certification is not a mandatory 0.5 gate; scientific APIs remain experimental until evidence supports promotion. 0.6.0 remains Orbits, with the existing planned sequence intact.
