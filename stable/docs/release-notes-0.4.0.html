Azimlib 0.4.0 — unreleased, re-scoped development draft

This is not final acceptance or publication approval. Candidate metadata is 0.4.0; the published package remains 0.3.0. No accepted final 0.4 release, tag or uploaded PyPI files exist.

Functional development additions

  • Own bounded PBF stream/index and regional real-data extraction; CRS/datum grids, planar/spherical topology, local geocoding and own road routing.
  • Optional international shaping/fonts and explicit external TeX toolchains.
  • Optional experimental own GPU rendering and bounded 3D volume visualization.
  • Terrestrial bounded Sun/Moon Artists, Earth–Moon views, local physical lighting and experimental finite-body eclipse visualization with explicit conventions.
  • Familiar root/pyplot imports, CPU defaults, editable/optional map components and separated static export/interactive viewers preserved.
