Estado dos cinco critérios

  1. Artists: aceito no catálogo 2D, com integração, auditoria e limites. Expansões da API permanecem no roteiro futuro, sem reabrir o corte por inferência.
  2. Composição: aceita nos cenários e limites: textos, componentes/atlas, 200 DPI, posição manual, toggles/resize/Home source/wheel.
  3. Visual: aceito no corte, com galeria, correções e verificação visual Windows; diferenças de raster/fontes/toolkit registradas, sem equivalência pixel a pixel.
  4. Desempenho: aceito localmente com base original/camadas, input humano, pintura Tk e limites. Pixels preservados, composição de pan novo acelerada e raster opcional próprio compilado; não promete rapidez arbitrária, latência do monitor ou outras plataformas.
  5. Release: CI efetiva aprovada nos três sistemas; aceite visual Windows e limites nativos Linux/macOS explícitos, no escopo de plataforma documentado. Build/instalação/auditoria 0.2.0 concluídos nos artefatos locais; publicação 0.2.0 no PyPI concluída.

Este registro complementa os critérios; não os substitui. Urbano, 3D, Qt e novos formatos ficam depois. Não há percentual/data estimados; novos subpassos só serão encerrados com evidência. Publicação PyPI é separada.
