Azimlib 0.4.0 — unpublished candidate API

GPU selection (Figure.show(renderer="gpu"), Figure/root/pyplot savefig(renderer="gpu"), GpuRenderer/GpuConfig) is experimental. Stateful root/pyplot show() has no renderer keyword. Astronomical eclipses, finite-source geometry and disk conventions are experimental, not certified forecasts. Private ephemeris APIs remain internal. PBF has regional real-data validation, not proven planet scale. CPU defaults and explicit refusals remain. Policy, scope, observed evidence.

Referência pública da Azimlib

Gerada por python tools/api_reference.py a partir dos objetos reais. Assinaturas descrevem a implementação atual, não compatibilidade integral com Matplotlib. Veja guia científico, componentes, limites de compatibilidade e matemática.

Coordenadas: longitude/latitude em graus. figsize: polegadas; linewidth, fontes e espaçamentos: pontos; s: pontos². set_extent/extent: (west, east, south, north). Arquivos PNG/SVG não incluem controles de UI.
