0.4 development benchmark consolidation

This earlier measurement snapshot is preserved as historical evidence. Current 14.03 consolidation is the release evidence ledger. Local measurements are consolidated in the machine-readable baseline, with report hashes and checked source-module identities. They establish reproducible bounded workloads, not global throughput or universal interactive performance.

Reproduction and measurement scope

Run timings serially on an idle machine; record OS/Python, CPU identification, GPU/driver/context, workload, repetitions, source hashes and resource policy. Keep RSS profiling in a separate run because sampling affects timing:

python -I tools/benchmark_foundation.py --output foundation.json
python -I tools/benchmark_topology.py --index-segments 20000 --polygon-vertices 32 --output topology.json
python -I tools/validate_gpu.py --output gpu-timing
python -I tools/validate_gpu.py --measure-memory --output gpu-memory

The foundation test has seven batches of 1,000 geocentric roundtrips, a 250 ms p95 budget and 4 MiB held-Python allocation budget. Topology tests 20,000 disjoint segments (zero candidate overlaps), two 32-vertex polygons and five analytic spherical lunes. Its 128 MiB tracemalloc ceiling is not native RSS, worst-case overlap complexity or a dense arbitrary-topology guarantee.

GPU timing reports 12 samples each for warm, pan, resume, zoom and temporal edits, separating scene composition from rendering. The GPU draw alone omits composition, GUI scheduling and physical mouse-to-display latency. The baseline's sequential FPS includes composition and draw; individual p95 values must not be added and represented as a measured combined p95. Zoom invalidates geometry caches and is substantially slower. The target of 33 ms/frame and 100 ms physical-input response is not established, and this scene's measured workload exceeds 33 ms.

The separate RSS probe sums the process and its workers, samples at 10 ms, can double-count shared pages and is not driver VRAM or an instantaneous hard quota. Record unavailable probes explicitly. Resource ceilings remain enforced by the reader/renderer contracts rather than inferred from one sampled peak.

Real regional PBF

The locally supplied frozen Geofabrik Monaco snapshot is 2026-01-01, SHA-256 2c0debd7676c0d0d80ec534251cb004a6797441d14512cb83d01fe1ad81363bf. It is OSM data under ODbL, © OpenStreetMap contributors; see optional data notices. No dataset download or embedding is performed by these benchmarks.

python -I tools/benchmark_pbf.py monaco-260101.osm.pbf --sha256 2c0debd7676c0d0d80ec534251cb004a6797441d14512cb83d01fe1ad81363bf --scope regional --dataset-version 2026-01-01 --source-url https://download.geofabrik.de/europe/monaco-260101.osm.pbf --missing skip --output pbf-regional.json

This recut has incomplete relations. Strict missing='error' rejects them; the explicit regional skip trial records omitted relations and verifies every input byte was consumed. It is not a complete-reference pass. The full-planet procedure retains strict references, independent counts, cgroup memory enforcement, pinned complete dump and resource measurements; see 2.08. Never download or run the planet dump on a machine with the current 20 GB trial ceiling. Preserve 15 GB free for the system.

Baselines and unfinished performance gate

Original integrated PNG/SVG/PDF scenes and native captures are generated by the integration validator; each manifest hashes outputs and runtime. Numeric suites retain analytic topology/geodesy checks and independent solar/lunar references. Approximate eclipse graphics are not a numeric baseline for real event prediction: that precision gate currently fails.

The original broader performance investigation called for representative large real datasets and dense urban/ overlapping topology cases on suitable hardware, measure disk and native memory, collect end-to-end native input latency, address scene composition/zoom costs, and re-run the declared budgets on the exact candidate. These remain unproved goals, not conditions silently passed by the current bounded consolidation. Small Monaco, disjoint segment indexing, software Mesa or isolated draw timings cannot substitute for these tasks.
